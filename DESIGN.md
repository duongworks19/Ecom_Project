# Pinterest-Inspired E-Commerce Design System (Vic Mart)
Adapted from DESIGN.md for an "All-Things-Online" multi-category shopping platform.

## Key System Tokens
- Primary: #e60023 (Pinterest Red)
- Primary Pressed: #cc001f
- Canvas: #ffffff
- Surface Soft: #fbfbf9
- Surface Card: #f6f6f3
- Secondary BG: #e5e5e0
- Secondary Pressed: #c8c8c1
- Surface Dark: #262622
- Ink: #000000
- Body: #33332e
- Mute: #62625b
- Hairline: #dadad3
- Focus Outer: #435ee5

## Shape Language
- 16px radius for buttons, inputs, product pins, category tiles
- 32px radius for modals, large feature cards
- 9999px pill for search bar, filter chips, badges
- 0px for layout strips and footer

## Typography
- Display XL: 70px / -1.2px letter-spacing (Manrope / Inter)
- Display LG: 44px / -0.8px letter-spacing
- Heading XL: 28px / -1.2px letter-spacing
- Heading LG: 22px
- Heading MD: 18px
- Body MD: 16px
- Body Strong: 16px font-weight 600
- Body SM: 14px
- Button MD: 14px font-weight 700
